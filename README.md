# Minecraft Crossover

**gta5** × Minecraft · visual · idea by the team

GTA V and Minecraft run live together: Minecraft blocks and creatures appear inside Los Santos and react to the player. The change shows in the first 30 seconds of play.

> I put a Minecraft house in Los Santos and let GTA traffic and TNT test it. The roadblock cars flipping like toys was my favourite part.

## Install

Needs GTA V (story mode only) with ScriptHookV and ReShade, plus Minecraft Java with Fabric. Copy the package folder's GTA files into the GTA folder and the jar into Minecraft's mods folder, start both games and pick Story Mode.
